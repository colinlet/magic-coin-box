## 📖 项目简介

《奇妙金币盒》是一个专为学龄前及小学低年级儿童（核心适用年龄：3-12岁）设计的行为管理与习惯养成系统。

它不仅仅是一个简单的“贴纸奖励表”，而是一个结合了**动态进阶、弹性容错与延迟满足**的完整微型经济系统。通过虚拟货币的流转，帮助孩子在充满仪式感和游戏化的体验中，逐步将外驱力转化为内驱力。

## 🧠 核心原理与底层逻辑

本系统基于以下心理学与行为学原理构建：

1. **代币制 (Token Economy)**：将抽象的“表现好”转化为具象的“金币”，建立清晰的因果反馈回路。
2. **多变比率强化 (斯金纳箱原理)**：通过“盲盒抽奖”机制，提供不可预测的惊喜，极大刺激多巴胺分泌，维持长期动力。
3. **延迟满足训练**：设计阶梯式的消费体系（从3币的即时快乐到50币的终极目标），引导孩子为了长远目标克制短期冲动。
4. **弹性容错机制**：首创“五选三”及格线，避免因一次小失误引发的“破窗效应”，保护孩子的安全感与积极性。

## 🎯 适用范围与生命周期 (四阶段动态演进模型)

本系统并非一成不变，而是随着孩子脑神经发育、教育阶段以及智能时代挑战的变化而动态演进的。我们建议将其分为四个核心阶段，最终目标是**帮助系统自身走向消亡，实现孩子的完全内驱**。

| 阶段划分 | 年龄段 | 核心发展目标 | 智能时代防御重点 | 金币盒应用建议 |
| :--- | :---: | :--- | :--- | :--- |
| **阶段一：启蒙期** | **3-5岁** (幼儿园) | 建立基础规则意识与生活自理能力，培养安全感。 | 现实物理世界锚定。防止过早的高频屏幕刺激。 | **必须即时反馈**。奖励多为实体陪伴和绘本，避免屏幕时间作为奖励。任务聚焦：自己吃饭/穿衣。 |
| **阶段二：塑形期** | **6-8岁** (小学低年级) | **本系统的黄金适用区。** 适应规则，培养基础学习习惯和延迟满足能力。 | 刻意保护和训练“深度专注力”。 | 开展延迟满足训练。利用盲盒机制刺激多巴胺。任务聚焦：按时作业、无屏幕专注20分钟。 |
| **阶段三：分化期** | **9-10岁** (小学中年级) | 从具体行为管理转向时间管理，建立双向契约精神。 | 辨别信息真伪，防止算法投喂导致的思维惰性。 | 父母单向发布任务转向**双向商定**。任务聚焦：自主规划复习、探索性提问。奖励增加特权类（如自由支配时间）。 |
| **阶段四：退场期** | **11-12岁** (小学高年级/初中) | 内驱力真正觉醒，青春期前额叶重塑，自我意识极强。 | 建立现实世界的高级成就感，抵御虚拟世界的“低动机状态”（躺平）。 | **微观代币制逐步瓦解。** 不再管理日常行为（如几点睡觉），转向宏观目标与项目制管理（PBL）。系统最终自然消亡。 |

> 💡 **核心提示**：在智能时代，金币盒系统的最高使命，不再仅仅是让孩子“听话”，而是通过物理世界的奖励和深度的亲子链接，在孩子的大脑被算法完全接管之前，帮他们抢回对自己注意力和多巴胺的控制权。
